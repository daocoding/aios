# Contributing
- Improvements to modules should keep the module contract (Purpose, When to run, Inputs, Procedure, Decision rules, Outputs, Human gate, Agent prompt spec).
- Back new decision rules with a reason (data, theory, or repeated field experience) and phrase them so they can be tested.
- Never commit tokens, passcodes, IP addresses, database files, or customer data.
- Keep the Python app dependency-free and the Cloudflare function API-compatible with it.
